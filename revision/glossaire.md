# Glossaire de révision

| Terme | Définition utile |
| --- | --- |
| ACL | Liste ordonnée de conditions et d’actions sur le trafic |
| Adjacency | Relation opérationnelle entre voisins d’un protocole ou information locale de forwarding, selon le contexte |
| AFI/SAFI | Identifiants de famille et de type d’information BGP |
| Airtime | Temps d’occupation du média radio |
| Anycast | Même adresse disponible sur plusieurs points, avec choix de chemin assuré par l’architecture |
| ARP | Résolution IPv4 vers une adresse de lien locale |
| AS | Système autonome dans le contexte BGP |
| AS_PATH | Attribut BGP décrivant un chemin d’AS |
| BDP | Produit débit-délai donnant un ordre de grandeur des données en vol |
| BFD | Détection de continuité d’un chemin selon une session |
| BGP | Protocole d’échange de routes et de politique |
| BPDU | Message de contrôle spanning tree |
| Bridge ID | Identité utilisée notamment pour l’élection de racine STP |
| BSSID | Identifiant d’une instance de cellule Wi-Fi |
| BUM | Broadcast, unknown unicast et multicast |
| CE | Équipement côté client d’un service opérateur |
| CIST | Arbre commun/interne dans le fonctionnement MST |
| CoA | Mécanisme d’autorisation dynamique RADIUS |
| Convergence | Réalignement des états et décisions après événement |
| CSNP/PSNP | Messages de synchronisation de base IS-IS |
| DAD | Détection de doublon d’adresse IPv6 |
| DIS | Rôle IS-IS sur réseau multi-accès |
| DNAT | Traduction de destination |
| DR/BDR | Rôles OSPF sur certains réseaux multi-accès |
| DSCP | Marquage DiffServ dans l’en-tête IP |
| DUAL | Algorithme de convergence EIGRP |
| EAP | Cadre de méthodes d’authentification |
| EAPOL | Transport d’EAP sur un lien dans 802.1X |
| ECMP | Répartition entre next-hops admissibles de coût égal |
| ESI | Identifiant de segment Ethernet dans EVPN |
| ESP | Protocole de protection IPsec |
| EVPN | Contrôle BGP de services Ethernet et overlays |
| FCS | Contrôle de validité d’une trame |
| FD/RD EIGRP | Feasible distance et reported distance utilisées dans le contexte DUAL |
| FEC | Classe de paquets ayant un traitement de forwarding équivalent |
| FHRP | Famille de mécanismes de passerelle redondante |
| FIB | Informations installées pour transférer les paquets |
| giaddr | Champ DHCPv4 utilisé notamment par le relais |
| Hop Limit | Limite de sauts IPv6 |
| IGP | Protocole de routage interne à un domaine |
| IKE | Négociation de sécurité pour IPsec |
| IRB | Intégration du routage et du bridging |
| LACP | Négociation d’agrégation de liens |
| LDP | Distribution de labels MPLS |
| LLDP | Découverte de voisins sur un lien |
| LOCAL_PREF | Préférence BGP au sein de l’AS |
| LSA | Information d’état de liens OSPF |
| LSDB | Base d’état de liens |
| LSP | Paquet d’état de liens en IS-IS ou chemin commuté par labels en MPLS, selon le contexte |
| MAC | Adresse de couche liaison ou fonction d’accès au média, selon le contexte |
| MAB | Accès fondé sur une identité dérivée de MAC |
| MED | Indication de préférence de chemin BGP sous conditions de comparaison |
| MLAG | Agrégation présentée par plusieurs châssis avec mécanismes de coordination |
| MSS | Taille maximale de données TCP annoncée par une extrémité |
| MSTI | Instance spanning tree dans une région MST |
| MTU | Taille maximale à préciser selon le niveau et le lien |
| NAC | Contrôle d’accès fondé sur identité et contexte |
| ND | Ensemble des mécanismes IPv6 de découverte et suivi de voisins |
| Next-hop | Prochain point de transfert d’une route |
| NLRI | Information de joignabilité transportée par BGP |
| OMP | Protocole de contrôle utilisé notamment dans Cisco SD-WAN |
| Overlay | Réseau logique construit au-dessus d’un transport |
| PAT | Traduction partageant des adresses à l’aide d’identifiants de flux |
| PE | Équipement fournisseur terminant des contextes de service |
| PHP | Retrait du label de transport à l’avant-dernier saut quand prévu |
| PMTUD | Découverte de la MTU du chemin |
| PVID | Classement VLAN de trames non taguées selon le port et la politique |
| RD VPN | Route Distinguisher différenciant des préfixes VPN |
| RIB | Table de routage du système |
| RPF | Vérification du chemin vers une source multicast |
| RSSI | Indication de puissance radio reçue |
| RT | Route Target utilisé dans une politique d’import/export |
| RTT | Temps aller-retour mesuré |
| SA | Association de sécurité IPsec |
| SACK | Information TCP sur des blocs reçus |
| SLAAC | Autoconfiguration IPv6 fondée sur des informations annoncées |
| SNAT | Traduction de source |
| SNR | Rapport signal/bruit |
| SPF | Calcul de plus courts chemins à partir d’une topologie |
| SSID | Nom de service Wi-Fi |
| SSM | Multicast dont la source est connue et demandée |
| TLV | Structure type, longueur et valeur |
| Underlay | Transport fournissant la connectivité à l’overlay |
| VNI | Identifiant de segment VXLAN |
| VRF | Contexte de routage distinct |
| VTEP | Extrémité de tunnel VXLAN |

Les termes polysémiques, notamment RD et LSP, doivent toujours être rattachés au protocole dont on parle.
